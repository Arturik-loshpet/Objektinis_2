\doxysubsection{Detailed Description}
Abstrakti bazinė klasė žmogaus vardui ir pavardei saugoti. 

Klasė naudojama kaip bendras pagrindas konkretiems asmenų tipams. Ji turi virtualų metodą tipui nustatyti, todėl tiesiogiai objektų iš jos kurti negalima.
